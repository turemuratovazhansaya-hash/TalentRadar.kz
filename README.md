# TalentRadar.kz
**TalentRadar.kz** — B2B-платформа для ВУЗов по поиску талантливых абитуриентов из регионов (г. Актобе).  🎯 **Разрыв:** ВИДИМОСТЬ   💡 **Решение:** Анонимный «Радар талантов», где ВУЗы находят школьников по навыкам и отправляют прямые офферы на гранты с согласия родителей.  *Специально для Gambit Hackathon 2026 (Трек «Талант до вуза»).*
