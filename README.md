# TalentRadar.kz 🛰️

**Платформа для выявления и поддержки региональных талантов в Казахстане.**

Проект создан в рамках хакатона **Gambit Hackathon 2026** (трек «Талант до вуза»).  
Цель проекта — устранить барьеры для школьников из регионов (например, Актобе) и помочь вузам находить талантливых абитуриентов через прозрачную и автоматизированную верификацию достижений.

---

## 🌟 Концепция проекта

*   **Проблема:** **Видимость** талантов из провинции перед столичными вузами и крупными университетами минимальна. Школьники теряются в общем потоке, а ВУЗы не могут эффективно находить талантливых ребят из регионов.
*   **Решение:** Анонимный **«Радар талантов»**. ВУЗы находят школьников по их навыкам и достижениям и отправляют им прямые офферы на гранты (с согласия родителей).

---

## 🛠 Используемые технологии

*   **Фронтенд:** HTML5, JavaScript (`index.html`, `_frontend.js`, `script.js`), стилизованный под современный design.
*   **Бэкенд:** Python, Flask (`main.py`, `backend.py`).
*   **База данных:** SQLite (файл `talentradar.db`).
*   **Конфигурация деплоя:** `render.yaml`, `Procfile` (для быстрого развертывания на Render.com).
*   **Тестовые данные:** `Mock_data.json` для быстрой инициализации базы.

🚀 Как запустить проект локально
1. Установите зависимости
Убедитесь, что у вас установлен Python (3.8+). Затем установите необходимые библиотеки из списка зависимостей:


pip install -r requirements.txt
2. Запустите сервер
Для запуска локального сервера выполните команду:


python main.py
После успешного запуска браузер откроет страницу по адресу:

Главная страница: http://localhost:5000
🧪 Работа с тестовыми данными
В репозитории присутствует файл Mock_data.json. При первом запуске система автоматически инициализирует базу данных (talentradar.db) и загружает демонстрационных пользователей (школьников и представителей вузов), чтобы вы могли протестировать функционал «Радара» и кабинеты.
